# EnigmaSuite
EnigmaSuite is the repository for Enigma Astrology Research, software that is aimed at supporting research into astrology. 
Enigma supports both quantitative and qualitative research.

Release 0.7 provides the basics: calculation, automatic recognition of geographic coordinates and timezones, drawing, analysis, specifics for declination, progressive techniques (including primary directions), astrological analysis of the Enneagram, and support for research.
More information: https://radixpro.com/enigma
