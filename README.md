# EnigmaSuite
EnigmaSuite is the repository for Enigma Astrology Research, software that is aimed at supporting research into astrology. 
Enigma supports both quantitative and qualitative research.

Release 0.8 will be the last version. I will rewrite it into a new version for Windows and a separate version for Apple. The Windows version will use C# but I will replace WPF with Avalonia and use Vertical Slice Architecture. For the Apple version, I will use Swift and SwiftUI.
More information: https://radixpro.com/enigma
