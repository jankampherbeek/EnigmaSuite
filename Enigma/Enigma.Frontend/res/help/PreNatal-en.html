PreNatal

Prenatal is a technique, developed by the Dutch astrologer Eg Sneek. It uses positions during the period after conception and projects these on the life of an individual. Please check the User Manual for more information on this technique.

Type of prenatal astronomical position

The standard approach of the PreNatal technique is to use the aspects and eclipses that occur during pregnancy. You can (de)select these at the top of the window. You can also (de)select ingresses (in signs) and changes in direction (direct to retrograde of the other way around).

Celestial points and aspects

Default, PreNatal uses the celestial points Sun, Moon, the planets and Pluto and it uses only one aspect: the conjunction. You will find the selected celestial points and aspects specified just above the tables. If you want to change the default selection, you can use the buttons Change points and Change aspects. Clicking one of these buttons will open a window where you can select the points or aspects that you want to use.

Events and prenatal positions

The main part of the screen shows a table of events and a table of prenatal positions. You can add an event by clicking the button New event. The events that you see in the list are the same as the events that you defined for transists, secondary directions and symbolic directions.

The content of the table of prenatal positions depends on your selection for the type of astronomical positions and the celestial points and aspects to use. The table shows the date a prenatal position should be effective in real life. The second column contains the type of the prenatal position. An aspect consists of the glyps of the two celestial points and the aspect. An eclipse shows a black circle (solar eclipse) or a black Moon symbol (lunar eclipse). An ingress is indicated by the glyphs for the celestial point and the sign that is ingressed. A change in direction is indicated by the glyph for the celestial point that changes direction and either a glyph for retrograde or for direct movement.

The next two columns show the celestial point and its position. Unless the prenatal position is an aspect, the second column with positions will be empty.

In the last column you will see the real date and time for the prenatal event.

Correcting the time of conception

Of course, the time for conception is not known. Enigma shows a guessed date and time. You can combine an event from real life and a prenatal position. You can select a line with the event by clicking that line (make sure to click on text in that line). The date of that event is automatically entered in the Date field. You can also enter a date manually. If the date is defined, you can select a line in the table with prenatal positions. Click the button Combine and Enigma will calculate the conception date and time that would result in a match between the event and prenatal position. The table with prenatal positions is automatically updated after using Combine.

The date and time for conception is shown in the top part of the screen. Standard conception is the guessed conception date and time. Actual conception is the date and time that corresponds to the joined event and position. Initially, the two dates are the same.

If you want to try another correction, you need to click the button Reset. Enigma will return to the starting point and ignore the previous correction.
