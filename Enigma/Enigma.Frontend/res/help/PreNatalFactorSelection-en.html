Celestial points for PreNatal calculations

Select the celestial points that you want to include in the PreNatal calculation. The screen shows all points in a list, points that are not selected in the current configuration are not shown.

If you are missing a point you need to redefine the configuration.

You can select one or more points by clicking the associated checkbox. Deselect by clicking again.

Click the button OK when you selected the points you want.
