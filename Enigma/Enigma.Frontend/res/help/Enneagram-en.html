Enneagram

Through the Enneagram window, you calculate the relative values of the nine Enneagram types. The calculation is based on an idea by Dutch researcher Sjoerd Visser. More information can be found in the user manual.

Overview

When you open the Enneagram window, Enigma immediately calculates the different values. You can see the results under the Overview tab. They are displayed in the table in the center, showing the number and name of each Enneagram type along with its relative strength. The table is sorted, with the strongest type at the top.

On the right, you'll see an Enneagram figure. Each Enneagram type is represented by a sphere, the strongest type is red, the second and third are orange, and the remaining spheres are blue.

You can view the meanings of each type by clicking on one of the spheres or on an Enneagram type in the list. A pop-up will then appear with the description of the type as provided by Sjoerd Visser.

By default, the planets indicated on the left will be used. The research behind this theory is based on these planets. You can disable planets to observe their effect. If you don't have a time but do have a date, you can turn off Include houses. Enigma will then omit calculations related to house positions.

You can enable Count Pluto twice. For the reasoning behind this, please refer to the user manual.

Please note that Enigma will always use Placidus and geocentric positions is this is the way that the original research was performed.

After you change one of the options, Enigma will immediately recalculate all Enneagram strengths.

Details

Under the Details tab, you'll find a list with all the specifics of the calculation. This overview may be useful if you wish to study how the calculation works.
