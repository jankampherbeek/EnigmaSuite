Input for an event

In this screen you define an event that can be analysed with progressive techniques.

Description. A descriptive text for the progressive event.

Date and time

Date. Enter the date in the format yyyy:mm:dd, so June 16, 2022 would be entered as 2022/06/16. Historical dates before the year 0 should have a negative year if you select the Astronomical year count. Otherwise, all years will be positive.

Time. Enter the time in the format hh:mm:ss, using 24 hour notation. 2h38m30s PM would be 14:38:30.

Location

Country. Select a country from the drop down list. You can type the first characters to quickly identify the country. Make sure you use the official English name. Netherlands and not Nederland or Holland.

City. After selecting a country you can select a city using the scroll down list. Just as for a country, you can type the first characters to easily find the city.

Longitude. The geographic longitude is automatically filled after you selected a country and a city.

Latitude. The latitude is also automatically filled.

Finish the definition of the event

Click the button Save to finish the definition of the event. If you made any errors, Enigma will show a popup with information about those errors. After you corrected the errors, you can again click Save.

Click the button Cancel if you do not want to continue.
