Charts wheel

This screen shows the chart that is currently active. If you change the size of the screen by drawing its borders, the drawing of the chart will automatically adjust.

At the bottom of the screen you will see information about the chart and the configuration that has been used.

If you are not sure about the birth time, you can select the checkbox No time. The figure will show no houses and the chart starts with zero Aries at the left.

By checking No aspects you can remove the aspect lines.

If you want a neutral background for the signs, click No sign colors.

Click the button Export to create an image of the chart and save it to your disk.
