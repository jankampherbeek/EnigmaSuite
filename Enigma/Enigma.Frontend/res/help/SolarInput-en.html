Input for a solar return

Here you can define a solar chart.

Age. Enter the age in years (use only whole numbers).

Sidereal return. Check this button if you want to calculate a sidereal return but want to use a tropical chart. This checkbox has no effect if you use a sidereal chart.

Relocation. If you want to use the location where the chart owner lives at the time of the solar, you can overwrite the birth location and enter other coordinates.

Please note that the selected configuration is used. If you selected a sidereal zodiac or a topocentric observer position, this will effect the results.

Calculate

Click the button Calculate to calculate the solar return. If you made any errors, Enigma will show a popup with information about these errors. After you corrected the errors, you can again click Save.

Click the button Cancel if you do not want to continue.
