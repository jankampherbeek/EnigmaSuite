Startpoint zodiac

This screen shows the radix chart with an alternative starting point for the zodiac.

Changing the startpoint

You can select any celestial point that you defined in the configuration. Enigma will default to the first of these points, probably the Sun.

If you select a point by clicking the associated radio button, Enigma will automatically re-calculate and show the chart with the new starting point.

Options

Just as with the usual chart figure, you can select to use separate background colord for the signs. You can also select to hide aspect lines or to show a chart without a known birth-time (no cusps and 0 Aries to the left).

Export

Use the button Export to save the chart figure to your disk in the png format, which you can easily print.
